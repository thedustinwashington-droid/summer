# Summer Parenting Scheduler

Static HTML/CSS/JavaScript app for drafting and saving summer parenting-time calendars.

## Highlights
- Local account creation + login (account number + password) with persistent browser session.
- Saved calendar versions per account via `localStorage`.
- Split options: alternating weekends, every other week, 2-2-3, and custom day-by-day month view.
- Indiana holiday override selector with multi-select checkboxes.
- Front-end share actions: download JSON, print, email draft, and share link.

## Run
Open `index.html` directly or host this directory with any static host (including GitHub Pages).
